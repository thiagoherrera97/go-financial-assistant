# Instruções para o Claude

## Commits

- Projeto pessoal: **commite cada alteração logo após concluí-la, sem pedir aprovação.**
- Um commit por alteração lógica (feature, fix, ajuste), assim que estiver pronta e verificada (build/testes passando, quando houver).
- Mensagens em português, no formato Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`...), com um corpo curto explicando o porquê.
- Commite só os arquivos da alteração; não inclua arquivos soltos não relacionados nem segredos (`.env`, credenciais).
- Commitar na `main` direto é ok. Push só se for pedido.
